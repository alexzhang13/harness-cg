Counting questions over long game transcripts are lost by reading or keyword-searching the text yourself: rolls are mostly bare numbers after the game master asks for a check, a roll with advantage is two dice, and casts are often indirect. One sub-call learns the log's format; reader sub-calls list every event chunk by chunk; Python does all counting and ordering. Then look at the events the question needs, run a check only when the inspect output or the question calls for one, and answer. Usually 4-5 turns: probe, extract, inspect, (one check), answer.

## Rules
- Turn 1 is exactly the probe code below. Do not print the context or search it with keywords.
- Turn 2 is exactly ONE of the extraction blocks below: SPELL if the question is about spells or cantrips, otherwise ROLL.
- Turn 3 is the inspect code below with EP / WHO / WHAT set from the question. Then answer, unless one of the two checks below applies (each at most once): the asked character has no or very few (fewer than 5) events (name resolution), or a ROLL question (never a SPELL question) counts rolls of ALL characters over the window or an episode -- not one character's or player's rolls (one shifted re-read). Answer by turn 5.
- SPELL questions never get a re-read: answer from the first pass (a spell re-read lists the same casts again on nearby lines).
- Answer with Python over `events`. Never print, search, read or count transcript lines (only the name-resolution check looks at the transcript), never re-run an extraction to "confirm" it, and when a check disagrees with the first pass, keep the first pass.
- A roll made with advantage or disadvantage is TWO rolls (the extraction adds the second die's row): never deduplicate `events` by line.
- Episode k means the k-th transcript here (`x["ep"] == k - 1`); "by the end of episode k" means `x["ep"] < k`. A roll type matches exactly ("Dexterity" is not "Dexterity Save"). Character names match case-insensitively by prefix (Molly = Mollymauk); "player X" means `p2c[X]`.
- Answer shape: an integer for counts/percentages (round), one name for a single item, a comma-separated list for list questions or ties (every tied name, spelled as extracted); an episode without a match is left out of a per-episode list (never None / none / a blank).
